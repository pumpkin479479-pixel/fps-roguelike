# M1 技術検証: 銃と弾幕の試作

設計書の M1 のうち「弾幕の負荷テスト」と「銃モデル1丁をパイプラインで試作」を入れた。
「Steam 経由2人接続」は Steam アカウントが2つ要るので別の PR にする。

## 遊び方(試射場)

Godot で `project.godot` を開いて F5。メインシーンは `scenes/test_range.tscn`。

| 操作 | キー |
|---|---|
| 移動 / ダッシュ | WASD / Shift(押している間) |
| ジャンプ | Space(空中でもう1回。跳んだ瞬間に入力方向へ向きを変えられる) |
| スライディング | 走りながら Ctrl か C(押している間。坂を下ると加速) |
| 回避 | Q か Alt(入力方向へ短く飛ぶ。0.3秒無敵、再使用2秒) |
| 射撃 / 構える / リロード | 左クリック / 右クリック / R |
| 持ち替え / 拾う | 1・2・ホイール / E(2丁まで。3丁目は今の銃と入れ替え) |
| 弾幕ショー / 銃を落とす | F3 / F4 |
| 操作説明の表示 / マウス解放 | F1 / Esc |

- 床に6種の銃が1丁ずつ落ちている。敵を倒すと 45% で銃が丸ごと落ちる。
- 同じ銃種でも、威力・連射・装弾数・リロード・拡散・弾速・反動・重さが毎回 ±15% ばらつく。レア度(コモン〜レジェンド)で威力に補正。
- 重さで移動速度が変わる: 3kg を基準に、重いほど遅く(最大 -25%)、軽い拳銃は +5%。持ち替えも重いほど遅い。
- 画面左上に FPS、弾の数、弾の更新にかかった時間を常に表示する。

## 弾幕の仕組み(`scripts/bullets/bullet_manager.gd`)

- 弾は1発ごとにノードを作らず、数値の配列で持つ。描画は MultiMesh 1つ(描画命令1回)、常にカメラを向く板に光の玉を描くシェーダー。
- 対敵の当たり判定は物理エンジンを使わず、4m のマス目の表で近くの敵とだけ距離を比べる。同じ敵への1フレーム分の命中はまとめて1回のダメージにする(ダメージ数字も1つ)。
- 対地形は物理エンジンへの線分の問い合わせを2フレームに1回に間引く。
- レールガンのような超高速弾は飛ばさず、撃った瞬間に判定して光の線だけ描く(貫通あり)。
- 外から使うのは `spawn()` / `hitscan()` / `register_target()` / `count` だけ。GDScript で足りなければこのファイルだけ C# / C++ に差し替える。

## 負荷テスト(`scenes/bench.tscn`)

弾数を 500 → 10,000 発まで段階的に増やし、各段階 5 秒のフレーム時間を記録する。動く的 150 体、地形判定あり、3割が自分の弾。

```
tools\bench\run_bench.bat          (Windows。終わると自動で閉じる)
tools/bench/run_bench.sh --headless (描画なしで弾の計算だけ測る)
```

結果は `%APPDATA%\Godot\app_userdata\fps-roguelike\bench\` に CSV で保存し、コンソールにも表で出す。
合格の目安: 5,000 発で平均 16.7ms 以下(60fps)、95% のフレームが 20.8ms 以下。

## 銃モデルのパイプライン(`tools/blender/`)

- `gunlib.py` が共通部品(押し出し、円柱、パレット、書き出し、確認用の3枚の画像)。`ak47.py` が1丁分の寸法と形。
- 実行: `tools\blender\build_all.bat`(`assets/models/guns/ak47.glb` と `tools/blender/renders/` の確認画像を作る)
- 部品は枠ごとに別オブジェクト: receiver / barrel / magazine / stock、動く部品 bolt_handle / trigger。
- 取り付け位置は全銃共通の名前の点: muzzle / attach_barrel / attach_magazine / attach_stock / attach_sight / attach_option。
- 色は共通パレットから選び、テクスチャは使わない。AK-47 は約1,250ポリゴン。
- 他の5種はまだ仮の箱モデル(`scripts/guns/gun_visual.gd`)。`scenes/gun_gallery.tscn` で6種を並べて見られる。

## 開発用

- `-- --screenshot=out.png --shot-frames=120` で、指定フレーム後の画面を保存して終了(AI の見た目確認用)。`--fire` で射撃しっぱなし、`--start-gun=ak47` で初期装備を変更。
- `godot --headless --path . res://tests/movement_smoke.tscn` で移動の数値を確認。
